# T61 — tagi audio dla T43

Mapa obejmuje 155 kwestii `line` i `after` z T43. Czterdzieści pięć kwestii otrzymało po jednym oszczędnym tagu reżyserskim na podstawie treści; pusty ciąg oznacza neutralne wykonanie bez tagu. Format odpowiada mapie klucz → tekst w `contrib/voice/tags.json`. Tagi nie są częścią napisów.

To propozycja, nie wynik odsłuchu: przed produkcją należy sprawdzić przypisanie mówców i przesłuchać próby, zwłaszcza interpretację humoru. Notatek nie zaliczono do dialogów. Nie dodawano kluczy i18n; lint CSV nie dotyczy.
