# T54 — opisy pozycji rachunku

Propozycje dla rodzin z T43 oraz wcześniejszych rodzin i wariantów, naprawy zegara i odmowy; pięć języków, maksymalnie 32 znaki. Rodzina time_lock oznacza naprawę, nie otwarcie. Przy odmowie tekst opisuje brak usługi, nie pozycję płatną. Nazwy kluczy są propozycją. Brak lokalnego checkoutu uniemożliwił uruchomienie i18n_lint.py; limit długości sprawdzono w Pythonie. Obejmuje również warianty rodzin wymienione w tools.json.
