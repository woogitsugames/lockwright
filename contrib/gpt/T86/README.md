# T86 — postęp rozdziałów

`chapter_progress.csv`: propozycja tytułu i jednego zdania dla każdego z dwunastu rozdziałów, w pięciu językach. W pierwszych sześciu zachowano nazwy rozdziałów z `docs/CLIENTS.md`; nazwy 7–12 są propozycjami opartymi na zleceniach `game/data/jobs/` i ich tekstach `game/i18n/content.csv`. Zdania nie zakładają kolejności wykonania pojedynczych spraw.

To nowe materiały, nie podmieniono istniejących kluczy; nazwy kluczy i warunki odblokowania ekranu musi ustalić integrator. Nie zweryfikowano dopasowania do UI ani korekty przez native speakerów. Stan źródeł `b50ea45`.
