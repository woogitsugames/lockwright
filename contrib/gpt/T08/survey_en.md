# T08 — Post-session survey (EN)

**Instructions for the organiser:** make a form with **exactly 20 questions, Q01–Q20**. Every question must be optional. Disable email collection, sign-in requirements and file uploads; do not add free-text fields, names, contact details, exact ages or diagnoses. No participant code is required in the survey. If linkage to observations is necessary, store a random code separately and treat the linked records as pseudonymous.

## Participant introduction

**Thank you for trying Lockwright.** Rate only the features you actually encountered. You may skip any question. If you did not see a feature, select “N/A — not experienced”. Do not provide information about yourself or anyone else. There are no right or wrong ratings.

**Scale for Q04–Q20:** 1 = strongly disagree; 2 = disagree; 3 = unsure; 4 = agree; 5 = strongly agree. **N/A** = I did not encounter this feature or cannot rate it. Show the full scale labels on each question; answers are optional.

## Questions

**Q01. How often do you play games on your phone?** (single choice)
- **0** — never
- **1** — less than 1 hour a week
- **2** — 1–5 hours a week
- **3** — more than 5 hours a week
- **X** — prefer not to answer

**Q02. Which options did you use during this session?** (multiple choice)
- **0** — none of these (exclusive choice)
- **A** — Reading Help / chalk marks

- **C** — sound captions
- **D** — wider success windows
- **E** — swapped thumb controls
- **F** — tension lock
- **G** — reduced motion or a screen reader
- **H** — not sure / cannot remember (exclusive choice)

**Q03. What did you feel during the two-tap haptic calibration?** (single choice)
- **2** — two taps

## Coding rules (organiser only)

- Q01: one code from 0/1/2/3/X; Q02: a set of option codes, with 0 or H exclusive; Q03: 2/1/0/X; Q04–Q20: 1/2/3/4/5/N/A/blank.
- **Never convert N/A into 3 or 0**. Blank means no answer and is distinct from N/A.
- For Q04–Q20, positive share = number of ratings 4–5 divided by number of ratings 1–5; always report the valid-response count.
- Q09, Q11, Q15–Q17 and Q20 will often be N/A for track A. This is expected.
- Formal A1/A2/A7/A9 acceptance is based on observed outcomes, not self-reported ratings.
