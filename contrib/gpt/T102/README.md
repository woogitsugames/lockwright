# T102 — karty obsady

Plik cast.csv zawiera jeden wiersz dla każdego z 64 identyfikatorów cast.*.name z game/i18n/content.csv. Sprawdzono, że zbiór odpowiada mówcom w tablicach lines i after wszystkich 83 plików game/data/jobs. Wiek, charakter i sposób mówienia zaczerpnięto z contrib/voice/CAST.md, game/data/voice_cast.json albo docs/CLIENTS.md §3; kolumna source wskazuje źródło. Tam, gdzie w użytym źródle nie podano informacji, wpisano „brak danych”. Opisy projektowe w języku angielskim pozostawiono w języku źródła.

Przybliżony wiek jest opisem projektu głosu i nie zawsze oznacza potwierdzony wiek fabularny. Hania jest postacią dziecięcą, lecz źródło opisuje dorosłą lektorkę z lekkim głosem. Starszy CAST.md wskazuje niezgodność portretu dyrektorki, ale docs/ASSETS.md opisuje późniejszą wymianę na wersję kobiecą. Współdzielone identyfikatory darek i oskar opisano także w T94.

Wątpliwość: zestawienie opisuje stan źródeł na main b50ea45, nie weryfikuje tożsamości głosu na koncie ani rzeczywistej jakości nagrań.
